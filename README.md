# Project 3 : Collection Manipulator

A simple Python program to manage student information using dictionaries and lists.  
This project allows adding, updating, deleting, and displaying student records, along with listing subjects offered.

## Short Details :
What it Does
- Add new students with details (Name, Age, Grade, Date of Birth, Subjects)
- Display all students in a neat format
- Update existing student information
- Delete student records
- Show all subjects offered

##  Features
- Add new students with details (Name, Age, Grade, Date of Birth, Subjects)
- Display all students in a clean format
- Update existing student information
- Delete student records
- Show all subjects offered
